# Golos — начитка, монтаж и озвучка своим голосом на других языках

Бесплатная программа для Windows. Всё работает на вашем компьютере, без ключей и подписок.

1. **Запись.** Начитайте текст в микрофон как получится — с оговорками и повторами.
2. **Монтаж.** Программа распознаёт речь (Whisper), сама находит дубли, фальстарты и «э-э», укорачивает паузы. Режьте по тексту (выделить слова → Delete) или по волне. Есть отмена, зум, прослушивание результата.
3. **Перевод через чат с Claude.** Кнопка «Скопировать запрос» → вставить в чат → нажать «Копировать» под ответом. Перевод подставится сам, с учётом длительности каждой фразы.
4. **Озвучка вашим голосом** (Qwen3-TTS, казахский — AIT-Syn). Несколько вариантов на фразу с автопроверкой; лучший выбирается сам, можно переслушать и поменять.
5. **Пакет для монтажа ролика.** Начитка и дорожки (WAV 48 кГц/24 бит, MP3), SRT, фразы отдельными файлами, `timings.json`. Zip сразу кладётся в буфер обмена.

## Требования
- Windows 10/11 x64, видеокарта NVIDIA (проверено под RTX 2080 Super, 8 ГБ). Без видеокарты работает, но очень медленно.
- ~15 ГБ на диске (компоненты ~4 ГБ + модели ~8 ГБ), интернет при установке и первом запуске.

## Режим без окна (для других программ)

С версии 0.4.0 в папке программы есть `golos-cli.cmd` — озвучка без окна, например для YouTube Faceless Studio.

- `golos-cli.cmd voices` — список голосов (создаются в окне Golos → «Голоса»).
- `golos-cli.cmd synth --job job.json --out ПАПКА` — озвучить сегменты текста. На каждый сегмент программа
  делает несколько вариантов, проверяет их распознаванием (Whisper) и берёт самый точный. Цифры, годы,
  проценты и суммы («$10T», «1990s», «3rd») перед озвучкой переписываются словами. На выходе для каждого
  сегмента: WAV 48 кГц/24 бит и JSON с таймингами каждого слова исходного текста, процентом ошибок и
  статусом `ok` / `needs_fix` (что пропущено или услышано не так).
- `golos-cli.cmd test-en` — проверка английского диктора на трудном тексте. В «Пуске» есть ярлык
  «Golos — проверка английского диктора».

Произношение английских названий можно поправить в файле `%APPDATA%\Golos\pronounce_en.json`
(`{"Nvidia": "en-VID-ee-uh"}`) или в поле `pronounce` задания.
